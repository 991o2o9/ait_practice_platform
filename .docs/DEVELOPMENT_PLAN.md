# План разработки проекта AIT Practice Platform

Данный документ описывает поэтапный процесс разработки платформы, начиная с серверной части (Backend), затем пользовательского интерфейса (Frontend) и заканчивая панелью администратора (Admin Panel).

## Этап 1: Backend (FastAPI, PostgreSQL, SQLAlchemy)
*Фокус: Создание фундамента данных, бизнес-логики и REST API.*

1. **Настройка БД и миграций:**
   - Настройка SQLAlchemy и Alembic.
   - Подключение к PostgreSQL через docker-compose.
2. **Модели данных (Entities):**
   - Создание моделей: `User`, `Project`, `Task`, `Submission`.
3. **Аутентификация и авторизация:**
   - Реализация регистрации и логина.
   - Генерация и валидация JWT-токенов.
   - Защита эндпоинтов (зависимости аутентификации).
4. **CRUD операции и бизнес-логика:**
   - API для получения списка проектов и заданий.
   - API для отправки решений на проверку.
5. **Сервис автопроверки (Grader Service):**
   - MVP-реализация безопасного запуска кода студента с помощью `exec()`.
   - Валидация результатов и сохранение статуса `Submission` (passed/failed).
6. **Интеграция AI (Claude API):**
   - Разработка сервиса генерации проектов и заданий.
   - Разработка сервиса для подсказок "Why failed?".

## Этап 2: Frontend (React, TypeScript)
*Фокус: Создание интерфейса для студентов, интеграция редактора кода и подключение к API.*

1. **Базовая настройка:**
   - Настройка роутинга (React Router) и стейт-менеджера.
   - Настройка HTTP-клиента (Axios/React Query) для связи с Backend.
2. **Авторизация и профиль:**
   - Страницы входа и регистрации.
   - Защищенные роуты (PrivateRoute).
3. **Каталог проектов:**
   - Главная страница со списком доступных проектов.
   - Отображение прогресса студента.
4. **Рабочая среда студента (IDE):**
   - Интеграция `Monaco Editor` для написания кода.
   - Интерфейс выполнения задачи (описание, таймер для Hard, подсказки для Easy).
5. **Взаимодействие с проверкой и AI:**
   - Отправка кода и отображение результатов (логи, ошибки).
   - Кнопка "Спросить AI" (запрос подсказки при ошибке).

## Этап 3: Admin Panel (React, TypeScript)
*Фокус: Создание панели управления для преподавателей/администраторов.*

1. **Инфраструктура админки:**
   - Настройка роутинга и UI админ-панели.
   - Проверка ролей (доступ только для `role = admin`).
2. **Управление контентом:**
   - Создание, редактирование и удаление проектов и задач вручную.
3. **AI-Генерация проектов:**
   - UI для создания проектов через текстовое описание (Prompt -> Claude API).
   - Предпросмотр сгенерированных задач перед публикацией.
4. **Мониторинг:**
   - Просмотр статистики по студентам и их решениям.

## Этап 4: Финализация и полировка
*Фокус: Тестирование, геймификация и подготовка к релизу.*

1. **Связывание и тестирование:**
   - Сквозное тестирование всех флоу (от создания задачи до ее решения).
2. **Геймификация и UI/UX:**
   - Полировка дизайна (Bootstrap 5, анимации, прогресс-бары).
   - Настройка Exam Mode (строгий таймер, блокировка подсказок).
3. **Деплой:**
   - Подготовка Docker-контейнеров для продакшена.
